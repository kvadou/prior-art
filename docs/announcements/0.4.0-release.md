Prior Art 0.4.0 makes research recommendations easier to check and contribute to.

- Practical feasibility checks cover account eligibility, APIs, permissions, human handoffs, cost and the smallest authorized workflow proof.
- Paired evaluation tooling validates recorded runs and reports human-reviewed rubric differences, elapsed time and cost when known.
- Three synthetic worked reports demonstrate UI, permissions and integration decisions.
- A contribution guide, issue templates and pull request template make failures reproducible.
- Offline CI covers tooling tests, package consistency and shell syntax.

Existing search flags are unchanged. Tooling requires Node 22.18+ or a newer supported release; no npm installation is required.

Evaluation limits: the sample records and reports are synthetic. This release does not establish improved agent performance. We welcome paired real-task evaluations, including failures.

Start with the README for installation and CONTRIBUTING.md for feedback.
