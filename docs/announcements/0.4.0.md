## GitHub discussion or longer social post

I built Prior Art because I want coding agents to learn from existing implementations before committing to a design.

It researches repositories, official APIs, standards and failure histories, then separates what the sources actually show from what the agent recommends. The output is a decision, its tradeoffs and a concrete way to verify it.

Version 0.4.0 adds a practical feasibility check: does the proposed solution work with the account, APIs, permissions, budget and human workflow you actually have? It also includes worked examples and tooling for recording paired runs with and without the skill.

I have not established that it improves agent performance across tasks. The offline tests check tooling behavior; the examples are synthetic. I'd like help measuring the real thing.

Try it on a real task and open an issue with the model, skill version, constraints, what helped and what failed. Redact private information. Contributions that reproduce a bad recommendation or show a better decision are especially useful.

The repo includes installation instructions for Claude Code and Codex, a contribution guide and issue templates. It's MIT licensed.

https://github.com/kvadou/prior-art
